# Eidolon V1 Goal

The first serious release should prove that an agent doing real work can visibly feel like one persistent persona.

## Acceptance sequence

1. Attach to an existing Codex or OpenCode session.
2. Display the correct session source, adapter kind, session identity, and title.
3. Represent live operational state faithfully.
4. Animate and speak naturally around actual agent responses.
5. Handle multiple concurrent sessions without confusing their state.
6. Remain unobtrusive while the terminal carries dense work.
7. Survive restart without feeling like the persona has been reset.
8. Support a small number of surgical interventions such as approve, cancel, pause, or redirect.
9. Consume little CPU and GPU while idle.
10. Require almost no explanation after installation.

## Core experience

The user continues working in their preferred terminal or agent interface.

Eidolon supplies the parallel channel for:

- presence;
- attention;
- operational state;
- short dialogue;
- expression;
- interruption;
- approval requests;
- relationship continuity.

## Success criterion

The user should feel:

> the agent doing my real work is now visibly her.

Removing Eidolon should feel like losing the agent’s presence, not merely hiding an animation.
